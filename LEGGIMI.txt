PATCH CORRETTA – INSTALLER MODERNO WINDOWS

Corregge l'errore GitHub Actions:
  File 'Assets\\app.ico' cannot be found

La patch ripristina tutti i file grafici richiesti sia dal progetto .NET sia da Inno Setup:
- Assets/app.ico
- Assets/wizard.bmp
- Assets/wizard_small.bmp
- Assets/installing_a.bmp
- Assets/A.png
- Assets/installer_header.bmp
- Assets/installer_splash.bmp

Uso su macOS:
1. Estrarre lo ZIP.
2. Clic destro su APPLICA_PATCH_INNO_MAC.command > Apri.
3. Trascinare la cartella principale della repository nel Terminale e premere Invio.
4. Eseguire git add -A, commit e push.
