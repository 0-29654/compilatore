PATCH INSTALLER MODERNO INNO SETUP - SOLO WINDOWS

Modifiche:
- schermata iniziale più moderna con logo grande;
- finestra di preparazione compatta, centrata e con angoli arrotondati;
- barra animata con timer nativo di Windows;
- stile Segoe UI, pulsanti più larghi e layout pulito;
- immagine grande durante l'installazione mantenuta;
- nessuna modifica al programma C# o al workflow Windows.

Applicazione sul Mac:
1. Estrai lo ZIP.
2. Clic destro su APPLICA_PATCH_INNO_MAC.command > Apri.
3. Trascina la cartella locale della repository nel Terminale e premi Invio.
4. Esegui nella repository:
   git add -A
   git commit -m "Installer Inno moderno con barra animata"
   git push
