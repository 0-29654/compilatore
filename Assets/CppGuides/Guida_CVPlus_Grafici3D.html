CV+ Grafici 3D

Questa estensione è già inclusa in CV+ Compilatore Alunno. Non devi installare nulla.

1. Include

#include <cmath>
#include <cvplus_3d.hpp>

2. Disegnare z = f(x,y)

Usa cvplus3d::grafico passando una funzione con due variabili x e y.

cvplus3d::grafico([](double x, double y)
{
    return x * pow(y, 5) + x * log(y) + x * y;
}, -2.0, 2.0, 0.25, 1.5,
   "z = x*y^5 + x*log(y) + x*y");
Attenzione: log(y) richiede y > 0, per questo nell'esempio l'intervallo di y parte da 0.25.

3. Significato dei parametri

grafico(funzione, xmin, xmax, ymin, ymax, titolo, campioni);

xmin/xmax: intervallo dell'asse X. ymin/ymax: intervallo dell'asse Y. titolo: formula mostrata sopra il grafico. campioni è facoltativo e controlla la definizione della superficie.

4. Interazione

Dopo la compilazione si apre un grafico 3D locale nel browser. Trascina con il mouse per ruotare, usa la rotellina per ingrandire/ridurre e fai doppio clic per ripristinare la vista.

5. Programma completo

#include <iostream>
#include <cmath>
#include <cvplus_3d.hpp>
using namespace std;

int main()
{
    cvplus3d::grafico([](double x, double y)
    {
        return x * pow(y, 5) + x * log(y) + x * y;
    }, -2.0, 2.0, 0.25, 1.5,
       "z = x*y^5 + x*log(y) + x*y");

    return 0;
}
